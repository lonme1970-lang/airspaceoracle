Height exaggeration multiplies the distance above the ellipsoid for legibility, including both lower and upper surfaces. 1× is unexaggerated. Metadata always shows the original meter values. Overhead is a north-up camera, not a different projection.
Altitude integrity
There is no terrain model or geoid conversion. Source geometry and altitude interpretation are unverified. No operating schedule or activation is inferred.
Local KML / KMZ / GeoJSON
Local files are parsed in browser memory, not uploaded. KMZ support uses embedded JSZip 3.10.1 (MIT); it accepts a single KML document per archive, verifies CRC and limits total uncompressed content to 100 MB. External links, icons, overlays and network links are not fetched. Maximum 10,000 placemarks / 2 million coordinate positions. Polygon holes, multipart geometries, lines, points, folder paths, inline/shared styles and StyleMap normal styles are supported. Raw descriptions are shown as text, never executable HTML.
KML renders supplied 3D vertex geometry, including vertical wall faces, caps, lines and points. Meshes are triangulated in each face's own plane, batched per source and remain pickable. Raw Z and altitudeMode are retained. Missing Z defaults to 0 per KML. Clamp modes disregard Z; absolute uses numerical Z with geoid offset assumed zero; relativeToGround and relativeToSeaFloor add Z to a zero-height flat terrain/seabed approximation. No terrain, bathymetry or geoid model is loaded: this is not a precise MSL/AGL conversion. Extrude flags create only explicitly requested geometry down to that approximate baseline. Unclosed rings remain open linework. Tessellate flags are retained; faces use straight mesh triangles rather than sampled terrain-following surfaces. Source styles control fill and outline.
The height slider is display-only and starts at 1× true source scale. Use 3D view, select a feature and Focus to see walls; increase exaggeration if useful, without changing source values. N ↑ points north while retaining the center-ground target, range and tilt; if the view has no ground intersection, it preserves camera position and pitch instead.
Unlabeled description-table values such as FL, ALT, AGL, SFC and UNLTD are preserved in source order. They are not assigned floor/ceiling roles or converted where units/reference are unclear. Unknown limits stay unknown. The importer does not assert source currency, approval, or activation.
GeoJSON still accepts Polygon/MultiPolygon FeatureCollections. Only explicitly supplied numeric lower_m / upper_m with height_reference: ELLIPSOID are extruded. Otherwise it displays a footprint with unknown bounds, not fabricated heights. Coordinate Z and all properties are retained. Invalid imports leave existing data unchanged.
Each import adds an independent source root. Original Document and Folder nesting, including empty folders, is preserved. Expand branches to access child checkboxes. Parent checkboxes affect every descendant; identical names remain independent. Remove deletes only that source; Remove all sources returns to an empty globe.
A private populated download may contain the original KMZ as an embedded payload and load it with this same importer. Treat that HTML as sensitive: sharing it shares the dataset. The public shell contains no user dataset. Both versions need internet access for the renderer and basemap; these providers receive tile requests revealing the map extent, not your KML contents.
Connectivity & attribution
Application code is inside this HTML. It loads CesiumJS 1.124.0 (JS, CSS, workers and assets) from jsDelivr, and Esri World Imagery from ArcGIS Online. These external services receive your network requests and may change availability. No private token, account, backend or analytics is used. It is not an offline map. Imagery credits remain on the map; satellite capture dates vary.
